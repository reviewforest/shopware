Widget consent: storefront script test

Checks the cookie consent logic of the app's storefront script (RF-12254) without a shop. Open this file in a browser; file:// works. Every scenario runs the built script (Resources/app/storefront/dist/storefront/js/review-forest/review-forest.js, or the source with ?src=1) in its own frame. Nothing leaves the browser: the cookie is simulated and the loader script element is recorded instead of inserted. Shopware's cookie settings are simulated by the event they dispatch, CookieConfiguration_Update on the document. A real shop test is still needed.
